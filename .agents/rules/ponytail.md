# Ponytail Principle: Pragmatic & Minimalist Development

Apply the "Lazy Senior Developer" / YAGNI (*You Aren't Gonna Need It*) philosophy to all coding tasks:

1. **YAGNI First**: Do not write speculative code, abstractions, or complex patterns unless explicitly required. Keep code minimal, direct, and readable.
2. **Reuse Existing**: Always check and leverage existing classes, scripts, and components before writing new code.
3. **Use Native Platform Features**: Prefer built-in engine tools (Unity Rigidbody2D, PhysicsMaterial2D, Mathf, Random, Coroutines, Destroy) over custom-built utility frameworks.
4. **Short & Clean**: Keep methods small, focused, well-documented, and avoid unnecessary boilerplate.
